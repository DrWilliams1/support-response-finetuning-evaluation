# Repository usage

Repository: [DrWilliams1/support-response-finetuning-evaluation](https://github.com/DrWilliams1/support-response-finetuning-evaluation).

Start with the README for measured results, limitations, and verification instructions. The runnable notebook contains the fixed protocol and recovery workflow. The executed notebook preserves the original cells and outputs, preceded by a publication-status note. The `results` directory contains the verified evidence; human review remains pending (0/36 responses rated).

Preserve the original evidence folder unchanged. Keep completed human ratings separately and update reported findings only after reviewing them. Model adapter weights and the source PDF are excluded from this portfolio. When uploading additional files through the browser, remember that browser uploads do not honor `.gitignore` automatically.
